# Sophos-NGFW-Lab
Diseño y despliegue de arquitectura de red segura bajo el principio de Default Deny. Implementé un entorno con Sophos NGFW enfocado en segmentación lógica, hardening administrativo e inspección profunda. Proyecto orientado a la seguridad perimetral, la replicabilidad de infraestructuras críticas y la defensa en profundidad de grado empresarial.
